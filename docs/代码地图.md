## 一、总览

```
frontend/src
  main.js → App.vue → router/index.js → views/* → components/*
                │
           api/index.js（axios 拦截器）   store/auth.js（登录态）
                │  HTTP /api
                ▼
src/main/java/com/noteworkshop
  config（拦截器/分页/文档/初始化）
  security（JWT / 登录拦截 / 管理员拦截 / 上下文）
  user · note · comment · follow · admin · ai · file
  common（Result / 分页 / 异常）
                │
             MyBatis-Plus Mapper
                ▼
             MySQL 8.4
```

## 七、快速定位命令

```powershell
# 找方法/类

rg -n "api\.(get|post|put|delete)\(" frontend/src

# 找某个 URL
rg -n "/api/notes" frontend/src src/main/java
```
