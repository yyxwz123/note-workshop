## 每天怎么用（建议 90 分钟一轮）

1. **看知识点**（30 分钟）：先读通俗解释，再看代码位置，合上文档用自己的话复述；
2. **读代码**（20 分钟）：打开标注的文件与行号，对照"逐行读"理解设计意图；
3. **动手**（30 分钟）：按任务执行命令，记录实际输出，和预期对比；
4. **自测**（10 分钟）：先答题再看参考答案，答错的写进弱项清单。

## 通用约定

- 每份讲义的结构固定：**今天解决什么 → 知识点 → 代码逐行 → 动手 → 误区 → 自测 → 复盘**；
- 代码引用格式 `路径:行号`，行号以当前 `main` 分支为准；
- 命令默认在项目根目录 `note-workshop` 执行；
- 所有自测题答案默认折叠，先自答再看。
